# BUG-01: «Нийт ном» тоолуур хүснэгт дэх бодит мөрийн тооноос нэгээр илүү

Орчин: Уншлагын жагсаалт v2.0, Google Chrome 154.0.8037.92 (headless), Linux 7.0.0-38-generic x86_64, 2026-10-21

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан; анхны 3 ном.

## Дахин гаргах алхам

1. Аппыг шинээр асаагаад http://localhost:3000 нээнэ.
2. Хүснэгтийн өгөгдлийн мөрүүдийг тоолно.
3. «Нийт ном» тоолуурыг харна.

Хүлээгдэж байсан: «Нийт ном» хүснэгтэд харагдаж буй 3 мөртэй тэнцүү байна.

Бодит үр дүн: Хүснэгт 3 мөртэй боловч тоолуур 4 гэж харуулна. Нэг ном устгасны дараа 2 мөр үлдэхэд тоолуур 3 болж, бүх номыг устгасны дараа 0 мөртэй ч 1 гэж үлдсэн.

Ноцтой байдал: Major — хэрэглэгч жагсаалтын бодит хэмжээг буруу харж, устсан/байгаа бичлэгийн тоонд итгэх боломжгүй.
