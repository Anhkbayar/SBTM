# BUG-02: Хүснэгт оныг энгийн бүхэл тоогоор бус мянгатын таслалтай харуулдаг

Орчин: Уншлагын жагсаалт v2.0, Google Chrome 154.0.8037.92 (headless), Linux 7.0.0-38-generic x86_64, 2026-10-21

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан; анхны 3 ном.

## Дахин гаргах алхам

1. Аппыг шинээр асаагаад http://localhost:3000 нээнэ.
2. Анхны номын оны утгуудыг хүснэгтээс уншина.

Хүлээгдэж байсан: Он энгийн тоогоор, жишээ нь 1971, 2008, 1999 гэж харагдана.

Бодит үр дүн: Хүснэгтэд 1,971, 2,008, 1,999 гэж мянгатын таслалтай харагдана.

Ноцтой байдал: Cosmetic — утга уншигдах боловч заасан дэлгэцийн форматтай зөрнө.
